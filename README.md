# SpendLog

SpendLog is a web application for tracking expenses, managing wallets, and organizing expense categories.

Team Members

* Wyne Nadi - 6611919 
* Kaiming Zhou - 6632052


## Tech Stack

* **Frontend:** React, Vite
* **Backend:** Next.js Route Handlers
* **Database:** MongoDB

## Features

* Expense tracking
* Wallet management
* Expense category management
* Dashboard and spending summaries

## Project Structure

* `spendlog_frontend/` — Frontend application
* `spendlog-backend/` — Backend API and database models
